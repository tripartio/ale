# Print method for ALEPlots object

Print an `ALEPlots` object with the
[`base::print()`](https://rdrr.io/r/base/print.html) generic by calling
its [`graphics::plot()`](https://rdrr.io/r/graphics/plot.default.html)
method.

## Value

Invisibly returns `x`.

## Method usage

    print(x, max_print = 20L, ...)

## Method arguments

- `x`: An object of class `ALEPlots`.

- `max_print`: See the [plot()
  method](https://tripartio.github.io/ale/reference/plot-ALEPlots-method.md).

- `...`: Additional arguments (currently not used).
