# plot method for `ALE` objects

This [`graphics::plot()`](https://rdrr.io/r/graphics/plot.default.html)
method simply calls the constructor for an `ALEPlots` object.

## Method usage

    plot(x, ...)

## Method arguments

- `x`: ALE object.

- `...`: Arguments passed to
  [`ALEPlots()`](https://tripartio.github.io/ale/reference/ALEPlots.md)
